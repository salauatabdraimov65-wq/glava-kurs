В этом уроке

Шаг показывает, почему неоднородность пласта меняет расчёт фильтрационных потоков. стр. 443 написано моделью

Суть

Макронеоднородность — различия свойств значительных областей пласта, влияющие на фильтрационные потоки. В слоистой модели свойства постоянны внутри каждого слоя, но меняются между слоями. стр. 443 написано моделью

Как это работает

Механизм

Разные фильтрационно-ёмкостные свойства областей → различия фильтрационных потоков. Перетоки между слоями → для точного расчёта, вообще говоря, нужны двумерные задачи. стр. 443 написано моделью

Практика

Специалист схематизирует геометрию движения и подбирает эквивалентные коэффициенты фильтрационного сопротивления. Это позволяет применять формулы для однородного пласта. Для изолированных слоёв характеристики потоков можно рассчитывать по одномерным схемам. стр. 443 написано моделью

Нюансы

Хаотичные изменения проницаемости иногда позволяют считать значительные области в среднем однородными. В слоистой модели границы слоёв считаются плоскими, а свойства меняются только по толщине. При перетоках точный расчёт вообще говоря требует двумерной задачи. стр. 443 написано моделью

Как это работает

Механизм

Расход всего пласта складывается из расходов отдельных пропластков. Приравнивание этого расхода к расходу однородного пласта одинаковых размеров приводит к среднему значению kср = Σ(kᵢhᵢ)/h. стр. 446 написано моделью

Практика

Для гидродинамических расчётов заменяют неоднородный пласт однородным тех же размеров и задают ему среднюю проницаемость по формуле главы. стр. 446 написано моделью

Нюансы

Вывод дан для прямолинейно-параллельной фильтрации в слоистом пласте. По главе, средняя проницаемость не зависит от флюида и одинакова для несжимаемой жидкости и газа. стр. 446 написано моделью

Подробнее

Подробнее

Для однородной замены: Qₘ = kср(Pк − Pр)Bh/(μL). Приравнивание этих выражений даёт kср = Σ(kᵢhᵢ)/h. стр. 446 написано моделью

В этом уроке

Шаг показывает, как неоднородность проницаемости меняет распределение давления при потоке через зоны. стр. 447 написано моделью

Суть

В зональном пласте установившийся дебит одинаков во всех зонах, а при постоянном сечении одинакова и скорость фильтрации. Давление распределяется по каждой зоне отдельно. стр. 447 написано моделью

Как это работает

Механизм

Закон сохранения массы при установившемся течении требует, чтобы через каждую зону проходил одинаковый объем жидкости. Поскольку площадь сечения постоянна, одинаковы и скорости фильтрации; проницаемость зоны влияет на связь скорости с градиентом давления. стр. 447 написано моделью

Практика

Специалист рассматривает зоны длиной l_i с разными проницаемостями и пористостями, но постоянной толщиной и шириной пласта. Для расчета использует давления на концах каждой зоны и её длину. стр. 447 написано моделью

Нюансы

Рассматривается одномерное установившееся течение однородного флюида. Поток в каждой зоне прямолинейно-параллельный; границы зон перпендикулярны потоку. Формулы приведены, в частности, для несжимаемой жидкости. стр. 447 написано моделью

Подробнее

Для несжимаемой жидкости: w_x = (k/μ)(p_k − p_r)/L. стр. 447 написано моделью

Подробнее

Скорость и дебит слоя

Суть

При одинаковом перепаде давления скорость фильтрации выше в пропластке с большей проницаемостью. Дебит также зависит от площади сечения пропластка: он выше при большей проницаемости и большем сечении. стр. 445 написано моделью
