# Задание 01 — модуль проверки закладок (`review/`)
Исполнитель: Друг 1, Claude Code. Ветка `review`. Сначала прочитай `AGENTS.md`.

## Зачем
На тесте нам дадут чужой черновой пакет по тестовой главе с заложенными ошибками (≈20% целей). Модуль должен найти ошибки, дать исправление и страницу и **не трогать верное**. 10 баллов из 100: «≥70% ошибок с исправлением и страницей, ложных тревог ≤2». Тот же модуль потом проверяет наш собственный курс.

## Вход и выход
- Вход: `../пакет_вводных/02_модуль_проверки/контрольный_пакет/package.json` (схема `schemas/review_package.schema.json`), 81 элемент + 9 кадров PNG, глава — md книги.
- Глава: `load_chapter("vendelshtein_gl1")` из `glava/chapter.py` (страницы, текст автора, проверка цитат). На тесте глава придёт новым md: поддержи `--chapter-md путь.md` (тогда `load_chapter("test", md_path=...)` без диапазона страниц).
- Выход: `answer.json` по `schemas/review_output.schema.json`.
- Правила ответа и подсчёта: `../пакет_вводных/02_модуль_проверки/README.md` и `контрольный_пакет/README.md` — прочитай оба.
- Команда: `uv run python -m review.run <package.json> [--chapter-md X.md] -o answer.json`

## Как устроить (точность важнее полноты)
1. **Проверки кодом, бесплатно:** цитата есть в главе? страница верная? (`check_claim`). Расхождение текста утверждения и цитаты по числам, «всегда/любой/никогда», «выше/ниже», «растёт/падает», степени — кандидаты.
2. **Проверка моделью по каждой цели** (`glava.llm.ask_json`, tier `bulk`): дай модели элемент + текст страницы цитаты ± 1 соседняя + список категорий из README с определениями. Пусть вернёт `{has_error, category, severity, problem, fix, page_pdf, quote, confidence 0..1}`. Для `script_line` подставь утверждение из `claim_ref`; для `scene_fact` — спецификацию сцены (`scenes[0].spec`); для `analogy` — узел.
3. **Кадры** (`frames`): отправь PNG + `shows` + `label` + `frame_class` + `plaque` + инварианты спецификации в модель с картинкой (tier `strong`). Чек-лист кадра: глубина растёт вниз, газ над нефтью над водой, метка происхождения соответствует тому, как сделан кадр, преувеличение подписано числом, кривая согласована с разрезом — см. `domain/geology/physics_checklist.json`.
4. **Отсев:** сортируй по `confidence`, отдавай не больше ~25 замечаний и только выше порога. Помни: в пакете есть «верные, но неожиданные» утверждения — замечание к ним = ложная тревога. Замечание без страницы или без `fix` = половина балла, поэтому они обязательны всегда.
5. Порог подбирай на контрольном пакете, но **ключ `key.json` открывать только после прогона**. Ключа в папке нет — Лид запросит его у организаторов.
6. Предметные знания (что такое «переворот знака» в геологии и т.п.) — только в промптах-шаблонах внутри `review/` и в `domain/`, без упоминания конкретной главы.

## Бюджет
Не больше **$5** на весь трек. Сначала отлаживай на 10 элементах. Повторные прогоны с теми же промптами бесплатны (кэш). Остаток денег: `uv run python -m glava.llm`.

## Готово, когда
- [ ] `uv run python -m review.run …контрольный_пакет/package.json -o answer.json` отрабатывает без ошибок, ответ проходит `schemas/review_output.schema.json`.
- [ ] После получения ключа: `uv run python ../пакет_вводных/02_модуль_проверки/score_review.py answer.json key.json` — цель ≥70% по весу, ложных тревог ≤2. Записать результат в `review/RESULTS.md`.
- [ ] Работает с `--chapter-md` на произвольной главе (английский тоже: промпты не должны предполагать русский язык главы).
