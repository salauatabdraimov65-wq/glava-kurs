# Задание 03 — демо-курс (`course/`)
Исполнитель: Друг 3, Codex на Windows. Ветка `course`. Сначала прочитай `AGENTS.md`.

## Зачем
Итог, который видит жюри, — курс по каждой главе. Жюри открывает его локально в браузере **без сервера и интернета** и проходит как новичок. Курс собирается **программой из `layer.json` + `tasks.json`**, а не вёрсткой руками. На тесте один и тот же генератор соберёт курс по незнакомой главе — никаких текстов под конкретную главу.

## Вход и выход
- Вход: папка `runs/<chapter>/` с `layer.json`, `tasks.json`, `routing.json`, `illustrations.json` (+ файлы). Пока настоящих нет — работай на `samples/latyshova_mini/` (там нет routing/illustrations: генератор должен спокойно работать без них).
- Схемы: `schemas/node.schema.json`, `task.schema.json`, `routing.schema.json`, `illustration.schema.json`.
- Выход: `runs/<chapter>/course/index.html` (+ папка `assets/` при необходимости). Данные встраиваются в страницу (`file://` не даёт `fetch` JSON).
- Команда: `uv run python -m course.build <папка_с_layer.json>` (по умолчанию пишет в `<папка>/course/`).

## Требования ТЗ (раздел «Демо-курс»)
**Путь:** части и шаги в порядке графа (`order`, связи `prerequisite`), время на шаг, прогресс, возврат к месту (localStorage).

**Страница шага** (берём из узла; блок без данных просто не показываем):
| Блок | Откуда |
|---|---|
| Заголовок для новичка 3–7 слов + название из книги рядом | `title` (+ название раздела книги, если есть) |
| Суть, 2–3 фразы | `layers.main` |
| Как это работает — все мысли автора | `layers.mechanism`, `practice`, `nuances`, `deeper` + все `claims` |
| По шагам | если автор описывает процедуру (`decision_on_data`, нумерованные claims) |
| Разбор примеров из главы | `worked_examples`: условие, шаги, итог с числами автора |
| Понятия | `terms_introduced` |
| Частая ошибка | `misconception` |
| Что это значит для данных | `data_meaning` (гипотезы помечены «гипотеза») |
| Аналогия и где она ломается | `it_analogy` |
| Источник | **«стр. N» у каждого абзаца**, дословные цитаты автора (раскрываются по клику), пометка «написано моделью» для `by_model: true` |
| Задачи из книги | `book_tasks`: номер, формулировка, нужный рисунок |
| Иллюстрации | `illustrations.json` по `step_id`: картинка, подпись, alt, метка происхождения |

**Задания:** типы single, multiple, order (перетаскивание пальцем на телефоне + кнопки ↑↓ как запасной вариант), gap, calc (с `tolerance`, `unit`). Проверка сразу, потом показ верного ответа и `explanation` со ссылкой на утверждение.
**Карточки** на все узлы с отметкой «знаю / повторить» (localStorage).
**Конспект** с печатью в PDF (`@media print`) и **карта связей шагов** (SVG из `links`, без внешних библиотек).
**Медиа:** если в `routing.json` у узла есть ролик — встроить `video/<vid>/video.mp4`.

**Интерфейс:** телефон 390 px и десктоп 1280 px без горизонтальной прокрутки; светлая и тёмная тема; текст ≥16 px; alt у картинок; видимый фокус; клавиатура. Формулы `$…$` из главы — показать читаемо без интернета (простая замена индексов `_{}`/`^{}` на `<sub>/<sup>` и греческих букв; KaTeX можно положить локально в assets, если уложимся в 30 МБ). Курс без видео ≤30 МБ.

## Готово, когда
- [ ] `uv run python -m course.build samples/latyshova_mini` создаёт `samples/latyshova_mini/course/index.html`, открывается двойным кликом.
- [ ] Все 5 заданий образца решаются на телефоне (проверь в Chrome DevTools, режим iPhone, ширина 390).
- [ ] У каждого абзаца видна «стр. N»; блоки без данных не показываются пустыми.
- [ ] Генератор не падает, если нет `routing.json`/`illustrations.json` или у узла пустые поля.
