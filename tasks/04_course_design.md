# Задание 04 — внешний вид курса (`course/theme.css`, `course/assets/`, `course/ui.js`)
Исполнитель: Друг 2, Claude Code. Ветка `course-design`. Сначала прочитай `AGENTS.md` и `tasks/03_course.md` (требования ТЗ к курсу).

## Граница с Другом 3
Курс собирает `course/build.py` (Друг 3). Ты правишь **только** `course/theme.css`, файлы в `course/assets/` и новый `course/ui.js` (если нужен скрипт для удобства). Нужна другая разметка или поле в HTML — напиши Другу 3, что именно добавить; сам `build.py`, `player.js`, `interactives.*` не правь. Если `ui.js` новый — попроси Друга 3 подключить его в `build.py` одной строкой.

## Что сделать (по ТЗ, раздел «Демо-курс»)
1. Телефон 390 px и десктоп 1280 px: нет горизонтальной прокрутки, ничего не налезает, кнопки заданий удобно нажимать пальцем (≥44 px).
2. Текст ≥16 px, спокойная читаемая типографика; формулы, таблицы книги (`book_tables`) и графики не вылезают за экран (таблица — горизонтальная прокрутка внутри своего блока).
3. Светлая и тёмная тема (`prefers-color-scheme`), контраст текста достаточный; цвета — из `domain/geology/styleguide.json`.
4. Видимый фокус, работа с клавиатуры; метки «стр. N», «написано моделью», «гипотеза», «симуляция» заметны, но не мешают читать.
5. Печать конспекта (`@media print`) — без меню и кнопок.
6. Без внешних шрифтов и библиотек из интернета: курс открывается без сети. Курс без видео ≤30 МБ.

## Проверка
`uv run python -m course.build runs/<глава>` на всех 6 главах в `runs/`, открыть `runs/<глава>/course/index.html` в Chrome: режим iPhone (390) и 1280. Ошибок в консоли нет.

## Не трогать
Тексты, данные, порядок шагов (это из `layer.json`), `runs/`, `layer/`, `glava/`. Никакой вёрстки под конкретную главу.
