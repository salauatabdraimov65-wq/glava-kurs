# Задание 02 — видео (`video/`): только поддержка станка
Исполнитель: Друг 2, Claude Code. Ветка `video`. Сначала прочитай `AGENTS.md`.

Основная работа Друга 2 теперь — внешний вид курса (`tasks/04_course_design.md`). В видео делаем только то, без чего на тесте ролик не соберётся. Полировку роликов не делаем.

## Критично (до заморозки)
1. **Сборка не падает.** `uv run python -m video.build runs/<глава>/video/<vid>/spec.json --layout 9x16` и `--layout 16x9` на всех `spec.json` в `runs/` дают mp4 без ошибок.
2. **Есть шаблон на каждый тип, который выбирает конвейер** (`config/difficulty.json → scene_template`): `well_tool_curve`, `pressure_diffusion`, `section_through_time`. Если шаблона нет — на тесте ролик не соберётся.
3. **Неизвестный шаблон или кривой spec не роняет сборку:** понятная ошибка или запасная простая сцена (текст + подписи), а не падение.

## Не трогать
`layer/`, `glava/`, `runs/`, `course/build.py` и другие чужие файлы. Сценарии (`spec.json`) пишет конвейер (`layer.scenes`), не станок.
