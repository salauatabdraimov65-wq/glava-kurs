# Задание 02 — видео (`video/`)
Исполнитель: Друг 2, Claude Code. Ветка `video`. Сначала прочитай `AGENTS.md`.

## Зачем
На обучении нужны два ролика на разных главах: **шортс 9:16** (один механизм, 40–75 с) и **разбор 16:9** (решение на данных, 1,5–3 мин). На тесте ролик собирается замороженным конвейером на узел, который назначат организаторы — поэтому строим **шаблоны сцен**, а не ролики руками. Механизм и данные рисуются **кодом из одной модели состояния** (глубина прибора управляет и положением в кадре, и точкой кривой). Никакой генерации видео.

## Обязательно прочитать
- ТЗ, раздел «Классы кадров» и «Озвучка»: `../Хакатон «Глава → курс» — ТЗ для участников.html`
- Разборы эталонов: `../пакет_вводных/06_подача_и_референсы/разборы_4_роликов.md`
- Стайлгайд: `domain/geology/styleguide.json` (цвета только отсюда), словарь ударений `domain/geology/pronunciation.md`
- **Образец формата спецификации — спецификация организаторов**: `../пакет_вводных/02_модуль_проверки/контрольный_пакет/package.json → scenes[0].spec` и кадры `frames/F01..F09.png`. ВНИМАНИЕ: в этом пакете специально заложены ошибки — бери формат (template, params, beats, invariants, assumptions, exaggerations, plaque, prediction_question, transfer_question), а не содержание.

## Что сделать
1. **Формат `spec.json`** как у организаторов: `template`, `params`, `beats[]` (`say`, `claim_id`, `on_screen`, `label`, `frame_class`, `action`), `invariants`, `assumptions`, `exaggerations`, `plaque`, `prediction_question`, `transfer_question`, `data_it_bridge`. Каждая фраза `say` опирается на `claim_id` из `layer.json`.
2. **Шаблон 1 `well_tool_curve`** (тип «И» — косвенное измерение): разрез из слоёв (литология, флюид, проникновение), ствол, прибор на кабеле, трек кривой, которая **вычисляется** из свойств слоёв с окном усреднения прибора и рисуется до глубины прибора. Глубина растёт вниз и подписана. Метка происхождения («симуляция»/«схема»/«реальные данные»), плашка «не в масштабе: что и во сколько раз».
3. **Две раскладки** одного движка: 1080×1920 (шортс; безопасная зона 220 сверху, 380 снизу, 70 по бокам; подписи ≥44 px) и 1920×1080 (разбор; синхронные виды рядом).
4. **Озвучка: основной голос `edge-tts`** (нейроголоса Microsoft ru-RU, бесплатно, наружу уходит только текст сценария), **запасной — Silero TTS** (локально, понимает знак ударения U+0301 — им же озвучиваются слова, где edge-tts ошибается в ударении). Голос выбирается настройкой, без правки кода. Речь 110–150 слов/мин, фраза ≤15–18 слов, числа словами, аббревиатуры по словарю `domain/geology/pronunciation.md`. Громкость −16 LUFS (ffmpeg `loudnorm`). Длительность кадра каждой фразы = длительность её аудио → синхрон ≤0,5 с.
5. **Субтитры** вшиты (просмотр без звука), без формул и греческих букв.
6. **Сборка**: ffmpeg из `imageio_ffmpeg.get_ffmpeg_exe()` (уже установлен). Рендер кадров — matplotlib или Pillow.
7. **Паспорт** `passport.json` по `schemas/passport.schema.json` собирается автоматически из спецификации.
8. Структура ролика: крючок-вопрос в первые 3 с → пауза на предсказание → механизм → ответ → вопрос на перенос в конце.
9. Позже (утро): **шаблон 2 `pressure_diffusion`** (тип «Ф»: давление вокруг скважины во времени, кривые считаются по формуле из главы) — Лид даст спецификацию.

## Команда
`uv run python -m video.build runs/<chapter>/video/<vid>/spec.json` → `video.mp4`, `frames/`, `passport.json` рядом.

## Для разработки
Сделай `video/examples/demo_spec.json` по образцу (узел `latyshova.mud_controls_logs` из `samples/latyshova_mini/layer.json` или ложный ВНК) и добейся ролика 40–60 с. Настоящие спецификации из слоя Лид положит в `runs/`.

## Готово, когда
- [ ] Одна команда делает mp4 9:16 и 16:9 из `spec.json`; кадры совпадают с инвариантами (глубина вниз, кривая = слои).
- [ ] Голос без ошибок ударения в терминах, синхрон с кадром, субтитры читаются на телефоне.
- [ ] Генерация ролика не требует ручных шагов и не зависит от конкретной главы.
