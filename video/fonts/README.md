# Шрифты ролика
Лежат в репозитории, чтобы ролик выглядел одинаково на Mac и Windows.

| Роль | Шрифт | Лицензия |
|---|---|---|
| Заголовки | PT Sans Narrow Bold | ParaType Free Font License (PTSans-LICENSE.txt) |
| Субтитры, подписи | PT Sans Regular/Bold | то же |
| Цифры, теги, шкалы | JetBrains Mono | SIL OFL 1.1 (JetBrainsMono-OFL.txt) |
