# Глава → курс

Конвейер превращает главу книги по геологии или геофизике в проверенный демо-курс для новичка: путь из шагов, полное объяснение каждого шага со ссылками на страницы, задания с проверкой, карточки, иллюстрации и ролики. Плюс модуль проверки чужих черновиков.

**Учебный слой — единственный источник правды.** Курс, задания, иллюстрации и ролики собираются из `runs/<глава>/layer.json`, а не из книги напрямую. Исправили факт в одном месте — пересобрали всё, что от него зависит, одной командой.

## Быстрый старт для жюри

```
# 1. Один раз: установить uv (https://docs.astral.sh/uv/) и зависимости
uv sync
cp .env.example .env          # Windows: copy .env.example .env — вписать OPENAI_API_KEY

# 2. Открыть готовый курс (сервер и интернет не нужны)
open runs/latyshova_gl5_par17-20/course/index.html      # Windows: start runs\latyshova_gl5_par17-20\course\index.html
```

Материалы организаторов (`books md/`, `книги/`, `пакет_вводных/`) должны лежать в папке **над** репозиторием, либо путь к ним задаётся в `.env` → `MATERIALS_DIR`.

## Одна команда на главу

```
uv run python -m glava.pipeline <chapter_id>
```
Этапы: **layer** (учебный слой) → **illustrate** (иллюстрации к каждому шагу) → **scene** (спецификация ролика) → **course** (HTML-курс) → **video** (ролик). Каждый этап пишет строку в `metrics.csv`.

| Задача | Команда |
| --- | --- |
| Новая (тестовая) глава | `uv run python -m glava.pipeline test1 --md "путь/к/главе.md" --pages 12-30 --title "Автор. Глава…"` |
| Глава на английском | то же + `--lang en` (цитаты остаются на английском, курс — по-русски) |
| Глава другого домена (бурение) | то же + `--domain drilling` (нужна папка `domain/drilling/`, см. ниже) |
| Ролик на назначенный узел | `… --video-node <node_id> [--video-format short|long]` |
| Без рендера видео (быстро) | `… --no-video` |
| **Пересборка после правки факта** | поправить `runs/<id>/layer.json` → `uv run python -m glava.pipeline <id> --from illustrate` |
| Записать ручную правку в журнал | `uv run python -m glava.edit --chapter <id> --file <файл> --what "…" --minutes 5 --why "…"` |
| Проверить чужой пакет с закладками | `uv run python -m review.run <package.json> --chapter-md <глава.md> -o answer.json` |
| Остаток бюджета на модели | `uv run python -m glava.llm` |

## Как устроено (модель предлагает — код проверяет)

1. **Нарезка главы** (`layer/units.py`, без модели): главы режутся по меткам `<!-- page N -->` на единицы с устойчивыми id (`p095.03`). Колонтитулы, номера страниц, куски соседних разделов и **описания рисунков, вставленные моделью при распознавании** (`━━━ FORMAT …`), отделяются от текста автора.
2. **Извлечение утверждений** (`layer/build.py`, проход A): модель выписывает все мысли автора с дословной цитатой. **Цитата и страница проверяются кодом** (`glava/chapter.py → check_claim`); не нашлась — один проход ремонта, иначе утверждение отбрасывается.
3. **Группировка в шаги** (проход B, сильная модель) + код: каждое утверждение ровно в одном шаге, мелкие шаги сливаются, порядок по предпосылкам.
4. **Наполнение шага** (проход C): суть, механизм, практика, нюансы, частая ошибка (`misc.*`), «что это значит для данных», ИТ-аналогия с границей, «решение на данных», глоссарий. Всё написанное моделью помечено `by_model`, гипотезы — `hypothesis`.
5. **Задания** (проход D): 5 типов, ключи проверяются кодом (вариант существует, слова пропуска есть в тексте шага, у расчёта есть допуск).
6. **Маршрутизация и покрытие** — кодом: формат по типу трудности и видеоёмкости; каждая единица главы → шаг или причина.
7. **Иллюстрации** (`layer/illustrate.py`) — SVG-схемы кодом из слоя, метка «схема» на картинке.
8. **Сценарий ролика** (`layer/scenes.py`) — спецификация в формате организаторов; каждая фраза ссылается на утверждение; метку происхождения ставит код.
9. **Курс** (`course/`) и **ролик** (`video/`) — детерминированная сборка из файлов выше.

## Где что лежит

```
glava/        фундамент: главы и цитаты, вызов модели, конвейер, журнал правок
layer/        учебный слой, иллюстрации, сценарии, доменный пакет
course/       генератор HTML-курса
video/        станок «spec.json → mp4» (9:16 и 16:9), озвучка
review/       модуль проверки чужих пакетов
domain/       доменные пакеты (геология) — отдельно от кода
config/       главы (chapters.json), типы трудности
schemas/      схемы организаторов
runs/<id>/    результат по главе: layer, coverage, routing, tasks, illustrations, course/, video/
MANIFEST.md   модели, инструменты, что уходит наружу
manual_edits.csv  журнал ручных правок (совпадает с историей коммитов)
metrics.csv   токены, деньги, время по этапам
```

## Доменный пакет — отдельно от движка

`domain/geology/`: `styleguide.json`, `misconceptions.json`, `physics_checklist.json`, `pronunciation.md`, `notation.md` (обозначения и ловушки распознавания), `glossary.md` (RU/EN), `it_bridges.md`, `audience.md`. Код не содержит геологии. Новый домен: создать `domain/<домен>/` по той же структуре, прогнать главу с `--domain <домен>`, затем `uv run python -m layer.domain_pack <домен>` соберёт глоссарий и ИТ-мосты.
