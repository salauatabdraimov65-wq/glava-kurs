# Глава → курс

Конвейер превращает главу книги по геологии и нефтегазу в проверенный демо-курс для новичка: путь из шагов, полное объяснение каждого шага со ссылкой на страницу, задания с проверкой, карточки, иллюстрации, графики книги, пересчитанные по формулам, и ролики. Плюс модуль проверки чужих черновиков с закладками.

**Принцип: модель предлагает — код проверяет.** Каждое утверждение несёт дословную цитату и страницу, и код сверяет их с текстом главы. Каждый ключ задания проверяется кодом. Всё, что написала модель, помечено. Кадры роликов и графики считаются из модели состояния, а не рисуются генератором.

**Учебный слой — единственный источник правды.** Курс, задания, иллюстрации и ролики собираются из `runs/<глава>/layer.json`. Исправили факт в одном месте — одной командой пересобрали всё, что от него зависит.

## Быстрый старт для жюри

```
# 1. Один раз: установить uv (https://docs.astral.sh/uv/), затем
uv sync
cp .env.example .env          # Windows: copy .env.example .env — вписать OPENAI_API_KEY

# 2. Открыть готовый курс (сервер и интернет не нужны)
open runs/latyshova_gl5_par17-20/course/index.html      # Windows: start runs\latyshova_gl5_par17-20\course\index.html

# 3. Проверить всё по требованиям ТЗ (схемы, цитаты, покрытие, задания, иллюстрации, курс, ролики)
uv run python -m glava.check --all
```

Материалы организаторов (`books md/`, `книги/`, `пакет_вводных/`) должны лежать в папке **над** репозиторием, либо путь к ним задаётся в `.env` → `MATERIALS_DIR`.

## Одна команда на главу

```
uv run python -m glava.pipeline <chapter_id>
```

| Задача | Команда |
| --- | --- |
| Новая (тестовая) глава | `uv run python -m glava.pipeline test1 --md "путь/к/главе.md" --pages 12-30 --title "Автор. Глава…"` |
| На первой или последней странице куски соседних разделов | то же + `--start-at "<начало заголовка главы>" --end-at "<заголовок следующего раздела>"` |
| Глава на английском | то же + `--lang en` (цитаты остаются на английском, курс — по-русски) |
| Глава другого домена (бурение) | то же + `--domain drilling` (пакет `domain/drilling/`) |
| Ролик на назначенный узел | `uv run python -m glava.pipeline <id> --from scene --video-node <node_id> [--video-format short\|long]` |
| Быстро, без ролика / без самопроверки | `… --no-video` / `… --no-review` |
| Перезапуск с упавшего этапа | `… --from <этап>` |
| **Пересборка после правки факта** | поправить `runs/<id>/layer.json` → `uv run python -m glava.pipeline <id> --from illustrate` (схемы, графики, сценарий, ролик, курс) |
| Записать ручную правку в журнал | `uv run python -m glava.edit --chapter <id> --file <файл> --what "…" --minutes 5 --why "…"` |
| Проверить чужой пакет с закладками | `uv run python -m review.run <package.json> --chapter-md <глава.md> -o answer.json` |
| Метрики по шаблону организаторов | `uv run python -m glava.metrics` (конвейер делает это сам в конце) |
| Остаток бюджета на модели | `uv run python -m glava.llm` |

Порядок действий на тесте — [TEST_DAY.md](TEST_DAY.md).

## Как устроено

Этапы конвейера и что в каждом проверяет код:

| Этап | Что делает | Проверка кодом |
| --- | --- | --- |
| **layer** — нарезка (`layer/units.py`) | Глава режется по меткам `<!-- page N -->` на единицы с устойчивыми id (`p095.03`). Колонтитулы, куски соседних разделов и **описания рисунков, вставленные моделью при распознавании** (`━━━ FORMAT …`), отделяются от текста автора. | без модели |
| **layer** — утверждения (`layer/build.py`, проход A) | Все мысли автора с дословной цитатой | цитата и страница сверяются с главой (`glava/chapter.py → check_claim`); не нашлась — ремонт, иначе утверждение отбрасывается |
| **layer** — шаги (проход B, сильная модель) | Группировка в шаги по предпосылкам | каждое утверждение ровно в одном шаге; мелкие шаги сливаются |
| **layer** — наполнение (проход C) | Суть, механизм, практика, нюансы, частая ошибка, «что это значит для данных», ИТ-аналогия с границей, «решение на данных», глоссарий; обозначения — из `domain/<д>/notation.md` | всё написанное моделью — `by_model`, гипотезы — `hypothesis` |
| **layer** — задания (проход D) | 5 типов, ≥18 на главу | ключ существует, слова пропуска есть в тексте шага, у расчёта есть допуск |
| **layer** — таблицы, тип трудности, маршрут | Таблицы книги целиком (пометка о распознавании); тип трудности (М, В, И, Ф, П, Пр, Н, Р) отдельным проходом; формат шага | формат — только то, что реально собрано: «шортс» — только если ролик есть |
| **recall** — полнота по идеям (`layer/idea_recall.py`) | Сильная модель независимо, не видя слоя, составляет «ключ» идей по страницам главы; затем пропущенные идеи добираются | у добранных утверждений та же проверка цитаты |
| **review** — самопроверка (`review.self_check` → `layer/apply_review.py`) | Наш же модуль проверки читает слой как чужой пакет; замечания применяются к утверждениям, текстам шагов и ИТ-аналогиям | исправление опирается на ту же страницу; исходный текст и замечание сохраняются; задания на исправленных утверждениях снимаются |
| **illustrate** — схемы и графики (`layer/illustrate.py`, `layer/redraw.py`) | SVG-схема к каждому шагу; **графики книги, построенные по формулам, пересчитываются кодом** («перерисовано по рис. N, стр. M») | формула есть в тексте дословно, подпись «Рис. N» есть, форма кривых совпадает с рисунком, выражение — только из разрешённых функций; замеры и каротаж не перерисовываются |
| **scene** — сценарий ролика (`layer/scenes.py`) | Спецификация в формате организаторов; параметры сцены — из каталога станка | каждая фраза ссылается на утверждение; метка происхождения от кода; кадр в истинном масштабе гарантирован |
| **video** — станок (`video/`) | Кадры из одной модели состояния, озвучка edge-tts (запасной голос Silero), −16 LUFS, субтитры | инварианты сцены, синхрон фраз; сбой ролика не останавливает конвейер |
| **course** — демо-курс (`course/`) | Автономный HTML: путь, шаги, задания, карточки, конспект, карта связей, практикум на данных, калькулятор давления | телефон 390 px и десктоп 1280 px без прокрутки, светлая и тёмная тема |

После всех этапов `glava.metrics` пересобирает `metrics.csv`, а `glava.check` проверяет результат по требованиям ТЗ.

## Результаты

Обучающие и контрольные главы — один и тот же конвейер, без кода под главу:

| Глава | Шагов | Утверждений | Заданий | Покрытие единиц | Полнота по идеям | Исправлено самопроверкой (утв. / тексты / аналогии) | Модель, $ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Латышова, гл. V §17–20 | 42 | 334 | 77 | 99,4% | 96,4% | 7 / 27 / 1 | 0,93 |
| Басниев, гл. XXIII–XXIV | 38 | 378 | 71 | 99,4% | 99,2% | 5 / 20 / 0 | 0,71 |
| Кузнецов, гл. 10 | 27 | 232 | 47 | 99,2% | 95,3% | 12 / 15 / 1 | 0,42 |
| Вендельштейн, гл. I (контроль) | 36 | 338 | 66 | 100% | 98,4% | 8 / 34 / 0 | 0,27 |
| Баренблатт, §4 (контроль) | 22 | 209 | 37 | 100% | 94,6% | 9 / 11 / 0 | 0,16 |
| Барабошкин, §1–2 (контроль) | 24 | 172 | 43 | 100% | 98,7% | 2 / 9 / 2 | 0,13 |

- **Цитаты и страницы:** 100% утверждений сверены кодом с текстом главы (`glava.check`).
- **Полнота по идеям** — наш замер, аналог критерия «≥90% идей ключа»: ключ составляет модель, не видя слоя. Ключ жюри может отличаться.
- **Новичок решает 92–96% заданий** (прогон «новичка»-модели только по тексту шага, без книги).
- **Графики по формулам:** Басниев — рис. 23.1, 23.3, 24.1, 24.2; остальные рисунки (замеры, каротаж, статистика) модель честно отклонила с причиной (`runs/<id>/redraw_log.json`).
- **Деньги** — из `metrics.csv`, только вызовы, относящиеся к главе. Расходы на эксперименты (сравнение 4 моделей для типа трудности, прогоны модуля проверки) — отдельной строкой `_общие`.

### Модуль проверки закладок

Контрольный пакет организаторов: **88% найденного по весу**, ложных тревог 3. Собственные полигоны на всех типах элементов (утверждения, аналогии, строки сценария, факты сцены): 90% при 2 ложных тревогах. Ответ всегда проходит схему, даже при сбое модели. ## Где что лежит

```
glava/        фундамент: главы и цитаты, вызов модели, конвейер, проверка, метрики, журнал правок
layer/        учебный слой, полнота по идеям, применение самопроверки, схемы, графики по формулам, сценарии
course/       генератор HTML-курса
video/        станок «spec.json → mp4» (9:16 и 16:9), шаблоны сцен, озвучка
review/       модуль проверки чужих пакетов
domain/       доменные пакеты (geology, drilling) — отдельно от кода
config/       главы (chapters.json), типы трудности
schemas/      схемы организаторов
samples/      образец слоя, репетиционные тексты
runs/<id>/    результат по главе: layer, coverage, routing, tasks, illustrations, course/, video/
MANIFEST.md   модели, инструменты, что уходит наружу
manual_edits.csv  журнал ручных правок (совпадает с историей коммитов)
metrics.csv   строка на главу и этап: токены, деньги, узлы, секунды видео, человеко-минуты
```

## Доменный пакет — отдельно от движка

`domain/geology/`: `styleguide.json`, `misconceptions.json`, `physics_checklist.json`, `pronunciation.md`, `notation.md` (обозначения и ловушки распознавания), `scales.md`, `glossary.md` (RU/EN), `it_bridges.md`, `audience.md`. Код не содержит геологии. Новый домен — папка `domain/<домен>/` той же структуры, глава с `--domain <домен>`, затем `uv run python -m layer.domain_pack <домен>` (глоссарий и ИТ-мосты из слоя). Пакет `domain/drilling/` собран заранее и проверен репетицией.

## Честные ограничения

- Полнота по идеям — наш собственный замер: ключ составляет модель, а ключ жюри может отличаться.
- Тип трудности совпадает с типами пар глав из ТЗ на 88% шагов; ошибка типа меняет только формат шага, но не его содержание.
- Озвучка не проверяется распознаванием речи: проверяются темп, громкость и длительность фраз; ударения — по словарю `domain/<д>/pronunciation.md`.
- Рендер ролика занимает 2–10 минут на компьютере без видеокарты.
- Модуль проверки: слабее всего ловит тонко потерянные условия (`lost_condition`) — см. `review/RESULTS.md`.
- Часть расходов на модель до введения пометки «глава/этап» отнесена к главам по времени вызова; то, что отнести нельзя, — в строке `_общие`.
