# Глава → курс

Конвейер: глава книги → учебный слой → демо-курс, ролики, задания; модуль проверки чужих пакетов.
Правила для людей и ИИ-агентов — `AGENTS.md`. Задания треков — `tasks/`.

## Установка (один раз)
1. Установить `git` и `uv` (см. сообщение в чате команды).
2. Положить рядом с репозиторием папку материалов организаторов (`books md/`, `книги/`, `пакет_вводных/`) или указать путь в `.env` → `MATERIALS_DIR`.
3. В папке репозитория:
```
uv sync
cp .env.example .env     # Windows: copy .env.example .env
```
4. Проверка: `uv run python -m glava.chapter latyshova_gl5_par17-20`
