# Репетиционные тексты (незнакомые конвейеру)

Прогоны всего конвейера одной командой на текстах, которых конвейер не видел при разработке, — проверка обобщения перед тестом.
Результаты — в `runs/<id>/`, записи в `config/chapters.json` с `split: "rehearsal"` (`glava.check --all` их не трогает; проверка: `uv run python -m glava.check <id>`).

| id | Текст | Что проверяли |
|---|---|---|
| `rehearsal2` | Кузнецов, стр. 150–162 | незнакомый раздел обучающей книги |
| `en_smoke` | `well_logging_en.md` — статья «Well logging», английская Википедия (лицензия CC BY-SA 4.0) | английский язык |
| `drill_wiki_ru` | `drilling_ru_wiki.md` — статьи «Бурение», «Буровой раствор», «Противовыбросовое оборудование», русская Википедия (CC BY-SA 4.0), нарезаны на 6 «страниц» | сдвиг домена: `--domain drilling`, код не менялся; 7,8 мин, полнота идей 97,6%, цитаты 99/99, ролик на `section_through_time` |
| `reh_basniev_gl21` | Басниев, гл. XXI, стр. 442–456 | формулы, перерисовка графиков, все этапы конвейера; нашла падение при выборе узла под ролик (исправлено) |
