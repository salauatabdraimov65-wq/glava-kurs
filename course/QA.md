Команды проверки:

```powershell

uv run --no-sync python -m course.build samples/latyshova_mini
Get-ChildItem runs -Directory | ForEach-Object { uv run --no-sync python -m course.build $_.FullName }
```

Пять автоматических тестов прошли. `--no-sync` понадобился из-за ошибки TLS при
скачивании новых зависимостей видеотрека из `main`; сам курс использует стандартную
библиотеку, зависимости не добавлялись.

Браузерный инструмент разрешает только HTTP/HTTPS и заблокировал проверку `file://`.
Поэтому открытие двойным кликом в этой проверке не подтверждено. Все ссылки `src`
в шести сборках проверены: относительные файлы существуют, пропусков нет. CSS, JS
и данные встроены в HTML, загрузки JSON по сети нет. Размер HTML каждой главы —
0,7–1,4 МБ. Сгенерированные результаты не изменялись вручную и не включены в коммит.
