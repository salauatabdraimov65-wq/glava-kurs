# Мягкая маркировка ИИ-акварелей — 26.11.2026

На общей обложке и пейзаже шага метка «иллюстрация ИИ» впечатана в сам WebP:
небольшой курсив Georgia Italic цветом сепии, без рамки и плотной плашки.
На фактурной обложке под подписью мягкая растушёвка бумаги; у пейзажа шага
подпись расположена на чистом поле. CSS не рисует текст и не затемняет подпись.

## Файлы и происхождение
- `cover.webp`: 1279×720, 147 370 байт; `cover-mobile.webp`: 640×360, 46 966 байт.
- `hills.webp`: 1600×400, 54 592 байт; `hills-mobile.webp`: 640×160, 15 844 байт.
- Все варианты меньше 200 КБ. Новая генерация картинок не выполнялась:
  прежние акварели сохранены, добавлена только типографика средствами Pillow.
- В `cover.json` и `hills.json` записаны промпты, `by_model: true`, `hypothesis: true`,
  `label.embedded: true`, `label.tz_deviation: false`, шрифт, цвет, размеры текста и файлов.
  Там же сохранены описания содержимого изображений.

## Проверки
9 unit-тестов проходят. Собраны все 10 курсов командой:
```bash
uv run python -m unittest course.test_course
for d in runs/*/; do uv run python -m course.build "$d" || exit 1; done
git diff --check -- course
```

В Chrome проверены обзор и шаг Латышовой и Кузнецова: 390/1280 px,
светлая/тёмная тема — 16 экранов. Горизонтальное переполнение 0 px;
ошибок и предупреждений консоли нет. Мобильный размер подписи 16,875 px,
десктопный — около 23,7 px на обзоре и 24,5 px в шаге.
Границы текста пересчитаны с учётом размера фонового изображения, масштаба
и кадрирования: подпись целиком внутри видимой области во всех 16 случаях.
Снимки также просмотрены визуально. Привязка обложки `right bottom` сохраняет
подпись при кадрировании, мобильные варианты обеспечивают читаемый размер.

[Протокол](screenshots/after/signature-validation.json),

Требование о метке на самой картинке восстановлено. Это проверка данного
изменения; полный аудит всех критериев ТЗ здесь не заявляется.
Данные глав и общие файлы не редактировались. HTML в `runs/` пересобраны
программой и не включены в коммит. Зависимостей не добавлено.

## История
`validation.json` — расширенная проверка оформления, `art-safety-validation.json` —
первая версия с крупной плашкой, `cover-validation.json` — промежуточная версия
без метки. Эти протоколы описывают прошлые состояния. Актуальный —
`signature-validation.json`.
