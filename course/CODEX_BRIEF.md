# Задание для Codex: доделать дизайн демо-курса («мягкий атлас»)

Репозиторий: https://github.com/salauatabdraimov65-wq/glava-kurs, ветка **`course`**. Работай только в ней, в `main` не сливай (это делает Лид).

## 0. Подготовка
```bash
git fetch origin
git checkout course
git pull origin course
uv sync
```
Прочитай целиком: `AGENTS.md`, `tasks/03_course.md`, `tasks/04_course_design.md`, `course/DESIGN.md`. Правила проекта обязательны.
Менять можно только папку `course/`. Если нужна правка в `glava/`, `schemas/`, `config/`, `domain/` — не делай её, а допиши пункт в раздел «Нужно от Лида» файла `course/DESIGN.md`.

## 1. Что за проект
Конвейер «глава книги → учебный слой JSON → демо-курс HTML». Курс собирает `course/build.py` из `runs/<глава>/` (`layer.json`, `tasks.json`, `routing.json`, `illustrations.json`, `video/`) в один самодостаточный файл `runs/<глава>/course/index.html`. Он должен работать офлайн, на Mac и Windows, при пути с кириллицей и пробелами. Жюри проверяет курс на незнакомых главах, поэтому никакой подгонки под конкретную главу.

## 2. Целевой дизайн
Макет заказчика: светлая тёплая бумага с зерном, акварельные иллюстрации, один янтарный акцент, заголовки и текст шрифтами с засечками, мягкие тени вместо жёстких, светлая шапка и меню.
Состав обложки (нулевого экрана): шапка (логотип, общий прогресс, «Пройдено уроков: 0 / N», «Офлайн»), слева меню «Маршрут главы» (обзор, повторение, карта связей, конспект, список уроков), справа карточка с заголовком, коротким описанием, тремя цифрами с иконками (уроки, задания, минуты) и акварельной картиной.
**Важное решение заказчика: прогресс («Пройдено уроков», шкала) показывается только на нулевом экране (обзор курса). Внутри урока его нет** — только название, кнопка меню и тонкая линия «Урок N из M». Это уже сделано через `body[data-view]` в конце `course/theme.css`, не сломай.

## 3. Что уже сделано
- `course/domain_theme.py`: токены дизайна из `domain/<домен>/styleguide.json` (палитра слоёв, акценты, контраст WCAG, тёмная тема), загрузка заблуждений из `misconceptions.json`, функция `art_css()` вшивает картинки из `domain/<домен>/art/` или `course/art-staging/<домен>/` в CSS-переменные `--art-<имя файла>`.
- `course/build.py`: разметка шага (плашка с номером, вопрос до чтения, ролик из `video/` после «Сути», «мысли автора» с цитатой по клику, кнопка «стр. N» → скан из `runs/<id>/scans/pNNN.png`), домен берётся из `config/chapters.json`, флаг `--domain`.
- `course/player.js`: прогресс, окно скана, разбор неверного ответа с заблуждением из домена.
- `course/theme.css`: база «полевой атлас» и в конце блок правок «Мягкий атлас» по макету.
- Картинки в `course/art-staging/geology/`: `cover.webp` — общая ИИ-акварель обзора, `hills.webp` — сохранённый ИИ-пейзаж шага. Метки сняты по явной просьбе пользователя; это зафиксированное отступление от ТЗ, а не отмена требования организаторов.

## 4. Что осталось
1. Страница шага, практика, итог, карточки, карта связей, конспект — довести до мягкого стиля: убрать остатки жёстких теней и пёстрых цветов слоёв (отрезки маршрута в меню приглушить до янтарного/нейтрального), сохранить пометки «написано моделью» (пунктир) и «гипотеза» (штриховка).
2. Телефон 390 px и десктоп 1280 px: без горизонтальной прокрутки, текст ≥16 px, строка 60–75 знаков, кнопки ≥44 px.
3. Тёмная тема: светлые шапка и меню в тёмной теме остаются тёмными, проверить контраст.
4. Третьей картинки пока нет (её не успели сгенерировать). Нужна заставка шага ( бледные горы и облака, широкая полоса 4:1, низ — чистая бумага) → сохранить как `course/art-staging/geology/hills.webp` и использовать как фон плашки шага через `var(--art-hills)`. Остальные картинки тоже вшиваются как `--art-<имя>`; если файла нет, курс остаётся рабочим на нейтральной бумаге.
5. Не использовать слова «нефть», «пласт» и цвета пород в коде `course/` (кроме файлов домена и картинок). Подмена домена должна перекрашивать курс без правки кода: проверка `uv run python -m course.build runs/<глава> --domain <путь к копии домена с другой палитрой> --output <временная папка>`.
6. В конце обновить `course/DESIGN.md` и скриншоты в `course/screenshots/after/`.

## 5. Картинки
Стиль: акварель на тёплой кремовой бумаге, зерно бумаги, тонкие линии пером, без содержательных надписей (кроме обязательной метки «иллюстрация ИИ»), палитра охра/жжёная оранжевая/серо-голубой/песочный, янтарный акцент. Если можешь генерировать — делай сам; если нет, напиши заказчику готовое описание, он сгенерирует в ChatGPT и положит файл в `course/art-staging/geology/`. Сжимай в WebP ≤200 КБ (Pillow: `uv run python -c "from PIL import Image; …"`). Курс без видео должен весить ≤30 МБ.

## Обязательное ограничение ТЗ для картинок

Нейросеть рисует только атмосферу: небо, поверхностный пейзаж, оборудование
издалека, людей. На сгенерированных изображениях запрещены керн, шлифы,
разрезы и схемы недр, графики и кривые, надписи, цифры, логотипы, читаемые
экраны. Данные и факты главы показываются кодом по проверенному источнику.
Метка **«иллюстрация ИИ» должна быть впечатана в пиксели файла** (Pillow),
читаема на телефоне и не перекрываться оформлением. CSS-наложение метки
не подходит. Промпт, происхождение и параметры маркировки хранятся в JSON рядом.
Два нарушения считаются критическими для призового места; проверять до публикации.

## 6. Проверка (обязательно перед каждым пушем)
```bash
uv run python -m unittest course.test_course
for c in runs/*/; do uv run python -m course.build "$c" || echo "FAIL $c"; done
```
(на Windows: `Get-ChildItem runs -Directory | ForEach-Object { uv run python -m course.build $_.FullName }`.)
Открой минимум две разные главы (например `latyshova_gl5_par17-20` и `kuznetsov_gl10`) в браузере через локальный сервер (`python -m http.server`) на ширине 1280 и 390, в светлой и тёмной теме, без ошибок в консоли. Файлы `runs/*/course/index.html` не коммить без отдельной просьбы Лида.
