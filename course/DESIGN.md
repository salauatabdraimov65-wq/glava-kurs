# Дизайн курса: «Полевой атлас», максималистская версия

Состаренная бумага, чернильный контур, плитки с жёсткой тенью, цветные слои с условными знаками.
Скриншоты: `screenshots/before/`, `screenshots/after/` (Латышова и Кузнецов, 1280 и 390 px, светлая и тёмная тема, подмена домена).

## Откуда берутся цвета
`course/domain_theme.py` читает домен главы из `config/chapters.json` (`domain`, по умолчанию `geology`)
и строит CSS-переменные из `domain/<домен>/styleguide.json`:

| Переменная | Откуда |
|---|---|
| `--s0…--s7`, `--sN-on`, `--sN-text`, `--sN-pat` | первая группа цветов вида `{"ключ": {"color", "ru"}}` (сейчас `lithology`); узор — общий набор знаков по порядку |
| `--accent`, `--accent-2` | самый насыщенный цвет группы и самый насыщенный из далёких от него по тону |
| `--paper`, `--ink`, `--muted` (тёмная тема) | `background`, `panel`, `text`, `muted` |
| светлая тема | нейтральный «пергамент» в коде (запасной вариант) |
| текст заблуждения при неверном ответе | `misconceptions.json` по `options[].misconception` в `tasks.json` |

Контраст текста считается в коде (WCAG ≥ 4,6), поэтому любая палитра остаётся читаемой.
Проверка без правки кода: `uv run python -m course.build runs/<глава> --domain <путь к папке домена> --output <папка>`.

## Что сделано в курсе
- Обложка: иллюстрированный разрез из палитры домена; отметка уходит вглубь по мере прохождения.
- Маршрут главы: полоса в шапке и колонка в меню, по отрезку на шаг; цвет и знак = тип шага (легенда «Условные обозначения»).
- Шаг: «плашка» с номером, типом, временем; вопрос до чтения (первое задание шага); ролик из `video/<id>/` встроен после «Сути» с вопросом-предсказанием из `spec.json`/`passport.json`.
- Текст модели — пунктирная полоса и штамп «написано моделью»; гипотеза — штриховка и штамп «гипотеза».
- «Мысль автора» — пронумерованные плитки, дословная цитата раскрывается по клику; страница — штамп «стр. N», а при наличии `scans/pNNN.png` — кнопка «показать скан».
- Неверный ответ: верный ответ, текст выбранного заблуждения из домена, объяснение.
- `prefers-reduced-motion` отключает анимации; печать конспекта без меню и кнопок.

## Нужно от Лида (общие файлы)
1. **`domain/geology/styleguide.json` → секция `course`** (необязательная, код уже её читает):
   ```json
   "course": {
     "strata_group": "lithology",
     "accent": "#F0A35E",
     "accent_2": "#7FB3D5",
     "light": {"paper": "#F3E4C4", "paper_2": "#EAD6AE", "ink": "#2A1C10", "muted": "#6B5238"},
     "dark":  {"paper": "#0F1419", "paper_2": "#1A2129", "ink": "#ECEFF4", "muted": "#8A96A3"}
   }
   ```
   Без неё светлая тема берёт нейтральный пергамент из кода, акценты подбираются автоматически.
2. **Поле `pattern` у цветов литологии** (`"pattern": "dots" | "dash" | "brick" | "diag" | "cross" | "wave" | "ring" | "zigzag"`):
   сейчас узоры назначаются по порядку; с полем условный знак будет совпадать с принятым в атласах (песчаник — точки, известняк — кирпичи и т. п.).
   То же для `domain/drilling/styleguide.json`.
3. **Сканы страниц** `runs/<id>/scans/pNNN.png` пока нигде не собраны — кнопка «показать скан» появится автоматически, когда `layer.build` начнёт их класть.
4. **`routing.json`**: ролики сейчас находятся по `video/*/spec.json → node_id`; если маршрутизация будет писать `video_id` в маршрут — тоже подхватится.
5. В `course/interactives.py` у шаблона `pressure_explorer` остались доменные слова в подписях («от скважины») — шаблон пришёл из раннего кода; лучше брать подписи из `domain/` (например, `domain/<домен>/templates.json`).
