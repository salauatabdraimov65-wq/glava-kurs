# Дизайн курса: «Мягкий атлас»

Обновлено 26.11.2026. Тёплая светлая бумага с лёгким зерном, акварель,
заголовки и основной текст с засечками, один акцент из доменного пакета,
мягкие тени. Тёмная тема сохраняет тёмные шапку и меню. На обзоре — общая
акварель поверхности, неба и оборудования вдали; в шаге сохранён пейзаж гор.

## Откуда берутся оформление и данные
`course/domain_theme.py` читает домен главы из `config/chapters.json`
(поле `domain`, запасное значение `geology`) или из `--domain <имя/путь>`.

| Значение | Источник |
| --- | --- |
| Цвета легенды `--s0…--s7`, узоры | Именованная группа цветов в `styleguide.json`; необязательные `course.strata_group`, `pattern` |
| Акцент `--accent` | `course.accent` или цвет группы с наибольшей насыщенностью |
| Бумага и текст обеих тем | `course.light`, `course.dark`; запасная нейтральная палитра в сборщике |
| Контрастные подписи | Расчёт по бумаге и цветным подложкам |
| Картинки `--art-<имя>` | `domain/<домен>/art/`, затем `course/art-staging/<домен>/` для встроенных доменов |
| Разбор заблуждения | `misconceptions.json` по `options[].misconception` |
| Порядок и содержание | `layer.json`, `tasks.json`, `routing.json`, `illustrations.json` |

CSS, картинки оформления, JS и данные встраиваются в HTML. Внешние шрифты,
CDN и новые зависимости не добавлены. Цитаты и страницы по-прежнему берутся
из учебного слоя; генератор не содержит названий конкретных глав.

## Проверка
После исправления иллюстраций прошли девять unit-тестов и все десять сборок.
Обзор и шаг заново проверены в восьми комбинациях ширины/темы/главы;
консоль чистая. См. [протокол безопасности изображений](screenshots/after/art-safety-validation.json).
Предыдущая расширенная проверка мягкого атласа: В Chrome через локальный сервер
проверены Латышова (42 урока) и Кузнецов (27 уроков): 1280/390 px × светлая/тёмная
тема, обзор, материал каждого урока, практика, итог, карточки, карта и конспект.
Ошибок и предупреждений консоли нет. Подмена палитры и отсутствие иллюстраций
проверены отдельно; HTML открывался через `file://` при отключённой сети и пути
с кириллицей и пробелами. Подробности и границы проверки — в [QA.md](QA.md).

## Нужно от Лида (общие файлы)
1. **`domain/geology/styleguide.json` → секция `course`** (необязательная, код уже её читает):
   ```json
   "course": {
     "strata_group": "lithology",
     "accent": "#F0A35E",
     "accent_2": "#7FB3D5",
     "light": {"paper": "#F3E4C4", "paper_2": "#EAD6AE", "ink": "#2A1C10", "muted": "#6B5238"},
     "dark":  {"paper": "#0F1419", "paper_2": "#1A2129", "ink": "#ECEFF4", "muted": "#8A96A3"}
   }
   ```
   Без неё светлая тема берёт нейтральный пергамент из кода, акценты подбираются автоматически.
2. **Поле `pattern` у цветов литологии** (`"pattern": "dots" | "dash" | "brick" | "diag" | "cross" | "wave" | "ring" | "zigzag"`):
   сейчас узоры назначаются по порядку; с полем условный знак будет совпадать с принятым в атласах (песчаник — точки, известняк — кирпичи и т. п.).
   То же для `domain/drilling/styleguide.json`.
3. **Сканы страниц** `runs/<id>/scans/pNNN.png` пока нигде не собраны — кнопка «показать скан» появится автоматически, когда `layer.build` начнёт их класть.
4. **`routing.json`**: ролики сейчас находятся по `video/*/spec.json → node_id`; если маршрутизация будет писать `video_id` в маршрут — тоже подхватится.
5. Подписи `pressure_explorer` теперь нейтральные («начальная точка»); прежняя просьба о доменных словах в подписях закрыта.
6. **Контракт шаблонов интерактивов**: формулу, единицы, начальные параметры и предметные названия `pressure_explorer` следует передавать из `domain/<домен>/templates.json` или маршрута. Нужна согласованная структура входных данных от Лида; доменные файлы в этой задаче не менялись. Сейчас шаблон включается только явным маршрутом, а оформление и сборка другого домена уже работают.

## Правило для следующих иллюстраций
Нейросеть создаёт только атмосферу на поверхности. Керн, шлифы, разрезы,
схемы недр, данные, графики, кривые, надписи, цифры, логотипы и читаемые
экраны в ИИ-картинках запрещены. Исключение — обязательная метка
«иллюстрация ИИ», впечатанная в сам файл. Факты и научные схемы рисуются кодом
из проверенных данных. Исторические снимки `before/` не используются в курсе.
