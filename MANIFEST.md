# Манифест конвейера

Команда: «Глава → курс», 4 человека
Тег заморозки: `freeze` (ставится до выдачи теста)

## Модели

| Этап | Модель | Версия | Где работает | Что уходит наружу | Как заменить |
| --- | --- | --- | --- | --- | --- |
| Учебный слой: извлечение утверждений, наполнение узлов, задания | OpenAI `gpt-6-luna` | API, ноябрь 2026 | облако OpenAI | текст главы кусками | `LLM_MODEL_BULK` в `.env` |
| Учебный слой: группировка в шаги; сценарии роликов | OpenAI `gpt-6.1-terra` | API, ноябрь 2026 | облако OpenAI | список утверждений узла / главы | `LLM_MODEL_STRONG` в `.env` |
| Тип трудности шага (отдельный проход; выбрана после сравнения 4 моделей) | OpenAI `gpt-6.1-terra` | API | облако OpenAI | текст шага и его утверждения | `LLM_MODEL_STRONG` |
| Полнота по идеям: независимый «ключ» идей по страницам | OpenAI `gpt-6.1-terra` | API | облако OpenAI | текст страницы главы | `LLM_MODEL_STRONG` |
| Полнота по идеям: сверка идей с утверждениями, добор пропущенных | OpenAI `gpt-6-luna` | API | облако OpenAI | идеи, утверждения, текст страницы | `LLM_MODEL_BULK` |
| Самопроверка слоя (наш модуль проверки) и применение замечаний | `gpt-6-luna` + `gpt-6.1-terra` | API | облако OpenAI | утверждения, тексты шагов, аналогии, сценарий + страницы главы | `LLM_MODEL_BULK` / `LLM_MODEL_STRONG` |
| Графики книги по формулам: распознать формулу и кривые рисунка | OpenAI `gpt-6.1-terra` | API | облако OpenAI | описание рисунка и текст двух страниц | `LLM_MODEL_STRONG`; сам график считает и рисует код (matplotlib) |
| Модуль проверки: элементы пакета | OpenAI `gpt-6-luna` | API | облако OpenAI | элементы пакета + страницы главы | `LLM_MODEL_BULK` |
| Модуль проверки: кадры, скептическая перепроверка | OpenAI `gpt-6.1-terra` | API | облако OpenAI | PNG кадров + описание | `LLM_MODEL_STRONG` |
| Озвучка, основной голос | Microsoft Edge TTS (`edge-tts`), нейроголос ru-RU | edge-tts ≥ 7.3 | облако Microsoft | **только текст сценария** | `VIDEO_VOICE_ENGINE` / `video/settings.json` |
| Озвучка, запасной голос | Silero TTS (ru) | torch hub | локально | ничего | `VIDEO_VOICE_ENGINE=silero` |
| Иллюстрации к шагам | — (код, SVG) | — | локально | ничего | — |
| Графики книги, перерисованные по формулам | — (код: numpy + matplotlib, SVG) | — | локально | ничего | — |
| Кадры роликов | — (код: Pillow + numpy из модели состояния сцены) | — | локально | ничего | — |

Все вызовы моделей идут через один файл `glava/llm.py`: кэш ответов, учёт токенов и денег (`cache/spend.jsonl`), остановка по бюджету `LLM_BUDGET_USD`. Поставщик заменяется в этом файле, остальной код не меняется. Каждый вызов в журнале помечен главой и этапом — из журнала `glava.metrics` строит `metrics.csv`. Генеративного видео нет: кадры роликов и графики считаются кодом.

## Лицензии и данные
Тексты глав и PDF — материалы организаторов, в репозиторий не входят (лежат рядом, путь `MATERIALS_DIR`). Репетиционные тексты в `samples/rehearsals/` — статьи Википедии («Well logging», «Бурение», «Буровой раствор», «Противовыбросовое оборудование»), лицензия CC BY-SA 4.0. Цитаты в слое — короткие фрагменты с указанием страницы. Голоса Microsoft — по условиям Edge TTS; Silero — лицензия CC BY-NC-SA (некоммерческое использование, для демонстрации).

## Запуск
Одна команда на главу: `uv run python -m glava.pipeline <chapter_id>` (подробно — `README.md`).
