# Правила проекта «Глава → курс» (для всех ИИ-агентов: Claude Code, Codex)

Читай этот файл целиком перед любой работой. Нарушение правил ломает работу остальных трёх агентов.

## Что строим
Конвейер: глава книги (md + PDF) → учебный слой (JSON) → демо-курс (HTML), ролики, задания. Плюс модуль проверки чужих пакетов.
Жюри оценивает в первую очередь **тест на незнакомых главах** после заморозки кода. Значит: обобщение важнее красоты.
ТЗ: `../Хакатон «Глава → курс» — ТЗ для участников.html`. Материалы организаторов: `../пакет_вводных/`.

## Железные правила
1. **Никакого кода под конкретную главу.** Нельзя писать в коде «Латышова», номера страниц, конкретные термины. Глава задаётся только записью в `config/chapters.json` или путём к md.
2. **Геология — только в `domain/geology/`.** Код не знает, что такое нефть. Цвета, заблуждения, чек-листы, словари берутся из доменного пакета. Новый домен (бурение) = новая папка `domain/drilling/`, код не меняется.
3. **Цитата — дословно из md, страница — из метки `<!-- page N -->`.** Проверяй через `glava.chapter.check_claim`. Блоки `━━━ FORMAT …` в md написаны моделью при распознавании, это НЕ автор: `load_chapter` их вырезает в `figure_notes`.
4. **Всё, что написала модель, помечено** `by_model: true`; всё, чего нет в главе — `hypothesis: true`.
5. **Форматы — только схемы из `schemas/`** (это схемы организаторов). Добавлять поля можно, убирать обязательные нельзя.
6. **Модель вызывается только через `glava/llm.py`** (кэш, учёт денег, стоп по бюджету $25 на всю команду). Не создавай свой клиент OpenAI.
7. **Трогай только свою папку** (см. таблицу). Общие файлы (`glava/`, `schemas/`, `config/`, `AGENTS.md`) меняет только трек «слой»; нужна правка — напиши об этом человеку.
8. **Работает на Mac и Windows.** Пути через `pathlib`, файлы открывать с `encoding="utf-8"`, пути с кириллицей и пробелами.
9. **Не открывай `key.json`** контрольного пакета, пока модуль проверки не выдал ответ.
10. Запуск всегда через `uv run python -m <модуль> ...`. Зависимость добавляй через `uv add` и упоминай в отчёте.

## Треки и папки
| Трек | Папка | Кто |
|---|---|---|
| Фундамент, учебный слой, задания, маршрутизация, сборка всего | `glava/`, `layer/`, `config/`, `pipeline` | Лид + Claude |
| Модуль проверки закладок | `review/` | Друг 1, Claude Code |
| Видео: шаблоны сцен, рендер, озвучка | `video/` | Друг 2, Claude Code |
| Демо-курс (HTML) | `course/` | Друг 3, Codex (Windows) |

Задания треков: `tasks/01_review.md`, `tasks/02_video.md`, `tasks/03_course.md`.

## Где что лежит (контракт между треками)
```
runs/<chapter_id>/
  layer.json          # учебный слой (schemas/node.schema.json)
  coverage.json       # покрытие (schemas/coverage.schema.json)
  routing.json        # формат узлов (schemas/routing.schema.json)
  tasks.json          # задания (schemas/task.schema.json)
  illustrations.json  # иллюстрации (schemas/illustration.schema.json) + файлы в illustrations/
  scans/p095.png      # сканы страниц из PDF
  course/index.html   # ← собирает course/
  video/<video_id>/   # spec.json, passport.json, frames/, video.mp4  ← собирает video/
samples/latyshova_mini/   # маленький образец слоя и заданий — для разработки, пока нет runs/
```

## Команды (каждый трек обязан поддержать свою)
```
uv run python -m glava.chapter <chapter_id>                 # статистика главы
uv run python -m layer.build <chapter_id>                   # слой → runs/<id>/
uv run python -m course.build runs/<chapter_id>             # курс → runs/<id>/course/index.html
uv run python -m video.build runs/<id>/video/<vid>/spec.json  # ролик → video.mp4
uv run python -m review.run <package.json> -o answer.json    # замечания к чужому пакету
```

## Git
- Своя ветка: `review`, `video`, `course`. Коммить часто, маленькими шагами, сообщение по-русски: что и зачем.
- В `main` вливает только Лид (владелец репозитория). Перед pull request: `git pull origin main`, прогон своей команды, без ошибок.
- Никогда не коммить `.env`, ключи, `cache/`.

## Ручные правки
Любая правка результата (`runs/`) руками или через ассистента после прогона конвейера = отдельный коммит + строка в `manual_edits.csv` (время, глава, файл, что, человеко-минуты, людей, номер прогона, причина). Лучше чинить код, чем результат.
