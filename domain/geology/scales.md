# Типичные масштабы и скорости (доменный пакет: геология)

Подаётся в генератор сценариев роликов. Условные значения в сцене должны попадать в эти диапазоны,
если глава не даёт своих чисел. Выход за диапазон — только с подписью «преувеличено в N раз».

| Величина | Типичный диапазон |
| --- | --- |
| Рост рифа по вертикали | 1–10 мм/год = 1–10 м за тыс. лет |
| Мощность рифовых массивов | десятки — сотни метров (до ~1–2 км) |
| Скорость осадконакопления (шельф, дельта) | 0,1–10 мм/год |
| Проградация фронта дельты | метры — десятки метров в год, километры за тысячи лет |
| Размер пор в песчанике / известняке | 0,01–1 мм |
| Каверны | миллиметры — метры; карстовые полости — до десятков метров |
| Зона повышенной пористости / выщелачивания | метры — десятки метров по вертикали |
| Диаметр скважины | 0,15–0,3 м |
| Глинистая корка | 2–20 мм |
| Глубина зоны проникновения фильтрата | 0,1–2 м (иногда больше) от стенки |
| Мощность продуктивного пласта | 1–50 м |
| Глубина залежей | 1–5 км |
| Пластовое давление | 10–60 МПа (≈ 10 МПа на 1 км гидростатики) |
| Пластовая температура | 30–150 °C |
| Пьезопроводность κ | 0,1–5 м²/с |
| Проницаемость коллектора | 0,001–1 мкм² (1 мД – 1 Д) |
| Пористость коллектора | 5–35 % |
| Удельное сопротивление: глина / вода в пласте / нефтенасыщенный пласт | 1–10 / 0,5–5 / 10–1000 Ом·м |
