# Обозначения и ловушки распознавания (доменный пакет: геология, русская школа)

Подаётся в промпт при наполнении узлов. Цель — не перепутать обозначения при пересказе.

## Ловушка распознавания: кириллица в индексах
Распознавание часто подменяет кириллические индексы похожими латинскими буквами или нижними индексами:
- `n`, `ₙ`, `π`, `Π` в индексе обычно = **п** (пористость, пласт): Kₙ, k_n, K_Π → **Kп**; ρₙ, ρ_n → **ρп**
- `r`, `ᵣ` в индексе обычно = **г** (глинистость): K_r, k_rл → **Kгл**
- `B`, `b` в индексе обычно = **в** (вода): ρ_B, K_B → **ρв**, **Kв**
- `H`, `h` в индексе обычно = **н** (нефть): K_H → **Kн**
- `p` в индексе может быть **р** (раствор, ρр) — смотри по смыслу фразы
Решай по смыслу текста рядом с обозначением («коэффициент пористости Kₙ» → это Kп). В пересказе пиши правильное русское обозначение; цитата остаётся дословной.

## Основные обозначения
| Обозначение | Смысл |
| --- | --- |
| Kп (kп) | коэффициент пористости |
| Kп.эф | эффективная пористость |
| Kпр (kпр) | коэффициент проницаемости |
| Kн, Kв, Kг | коэффициенты нефте-, водо-, газонасыщенности |
| Kгл, ηгл | коэффициент глинистости, относительная глинистость |
| ρп, ρв, ρф, ρр, ρзп | удельное сопротивление пласта, пластовой воды, фильтрата, раствора, зоны проникновения |
| Pп, Pн | параметр пористости, параметр насыщения (Pн = ρп / ρвп) |
| αпс | относительная амплитуда ПС |
| ΔJγ | двойной разностный параметр ГК |
| κ (каппа) | коэффициент пьезопроводности |
| β* | коэффициент упругоёмкости пласта |
| ВНК, ГНК, ГВК, ГЖК | водонефтяной, газонефтяной, газоводяной, газожидкостный контакт |
