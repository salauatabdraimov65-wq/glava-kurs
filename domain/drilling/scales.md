# Типичные масштабы и скорости (доменный пакет: бурение)

| Величина | Типичный диапазон |
| --- | --- |
| Глубина скважины | 1–6 км (рекордные — свыше 12 км) |
| Диаметр долота / ствола | 0,1–0,9 м (под эксплуатационную колонну ~0,2 м) |
| Плотность бурового раствора | 1,0–2,3 г/см³ |
| Гидростатический градиент воды | ≈ 10 МПа/км (раствор 1,2 г/см³ ≈ 12 МПа/км) |
| Пластовое давление | 10–100 МПа |
| Механическая скорость проходки | 1–50 м/ч |
| Расход промывки | 10–70 л/с |
| Объём приёмной ёмкости | десятки м³; сигнал притока — прирост от 0,5–1 м³ |
| Скорость всплытия газовой пачки в растворе | ~0,1–0,5 м/с (сотни метров в час) |
| Забойная температура | 50–200 °C |
| Длина свечи при СПО | ~25–37 м |
