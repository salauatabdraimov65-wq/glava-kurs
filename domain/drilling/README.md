# Доменный пакет «бурение»

Собран заранее, до выдачи теста, из заготовок организаторов (пункты чек-листа и заблуждения про бурение) и общих знаний предметной области.
Код конвейера не менялся: глава прогоняется с `--domain drilling`, движок берёт всё отсюда.

| Файл | Откуда |
| --- | --- |
| styleguide.json | копия геологического (один курс, одни цвета пород и флюидов) + оборудование и кривые бурения |
| misconceptions.json | 9 общих заблуждений из заготовок организаторов + 7 заблуждений бурения |
| physics_checklist.json | разделы организаторов «Бурение и скважина», «Процессы», «Масштабы», «Объекты», «Кадры» + 4 пункта о барьерах и давлениях |
| notation.md, pronunciation.md, scales.md | обозначения, ударения, типичные масштабы бурения |
| audience.md | портреты зрителя (общие) |
| glossary.md, it_bridges.md | собираются из слоя тестовой главы: `uv run python -m layer.domain_pack drilling` |

## Время
- Заготовка пакета до теста: начало 01:10, окончание 01:10 (ИИ-агент, проверка человеком — дописать минуты).
- На тесте: правка под конкретную главу — ___ мин (записать).

## Шаблоны сцен
Подходят без изменений: `section_through_time` (ствол как разрез: подъём газовой пачки, уровень раствора, цементирование), `pressure_diffusion` (давление в пласте вокруг ствола). `well_tool_curve` — для каротажа в процессе бурения.
