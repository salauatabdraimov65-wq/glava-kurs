# Обозначения бурения (доменный пакет: бурение)

Подаётся в промпт при наполнении узлов. Распознавание часто подменяет кириллические индексы латинскими
(`n`→п, `r`→г, `B`→в, `H`→н) — решай по смыслу, в пересказе пиши правильное обозначение.

| Обозначение | Смысл |
| --- | --- |
| Pпл, Pгс, Pзаб, Pгрп, Pпогл | пластовое, гидростатическое, забойное давление, давление гидроразрыва, поглощения |
| ρр (γр) | плотность бурового раствора, г/см³ или кг/м³ |
| ЭЦП (ECD) | эквивалентная циркуляционная плотность |
| ГНВП | газонефтеводопроявление (приток пластового флюида в скважину, kick) |
| ПВО | противовыбросовое оборудование (превентор, BOP) |
| КНБК (BHA) | компоновка низа бурильной колонны |
| СПО | спуско-подъёмные операции (tripping) |
| УБТ | утяжелённые бурильные трубы |
| ВЗД, РУС | винтовой забойный двигатель, роторная управляемая система |
| МГР / ТМС (MWD/LWD) | телеметрия, измерения и каротаж в процессе бурения |
| SICP, SIDPP | давление в затрубье и в трубах после закрытия скважины |
